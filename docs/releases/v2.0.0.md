# Chorus 2.0.0

Released 2026-11-08, approved by the owner ("Approve v2.0.0"). Tag `v2.0.0` on `390d059` (the merge of PR #41 into `main`), the
same commit as the preview `v2.0.0-preview.4` that was installed and run before the production tag. Website: chorus-admin PR #15
(release metadata, install box, launchers, sign-up) and PR #16 (install.sh with `sh`).

## Changes since 1.0.11

**New**
- Chorus 2.0, the optional module: Welcome, Try Pro and the trial; Teammates, the Portal, plans, Processes, Failures; remote access
  through a private link and AI apps; Export to one zip.
- Chorus in the browser everywhere: `chorus` prints the browser address of the same Chorus; with no screen it serves for a browser;
  `chorus serve --host` (plan `docs/plans/2026-11-07-browser-everywhere-and-docker.md`).
- The Chorus box (Docker, `docs/features/docker-box.md`): `ghcr.io/chauvoluuhuong/chorus-box` with the tested CLIs; `docker.sh` and
  `docker.ps1` on the website; the CLIs sign in from the page; open on the network (token in the address).
- Continue a chat whose CLI lost its session; a handoff can carry a note; New chat as one message box; the Doctor rechecks while an
  agent waits; one agent status everywhere.

**Fixed**
- `chorus serve` no longer stops when a link opens in a container, or when a chat's folder is missing; the box doesn't copy the
  host's chats.
- Approvals no longer pop up at the bottom; a removed project stays removed.
- Website: Pro sign-up worked for nobody new (Firebase sign-up was off: `ADMIN_ONLY_OPERATION`), now on; no forced Terms tick;
  `curl … | sh` failed at the unpack step since 2026-10-25, now plain sh.

## Evidence
- `npm test` 205 pass, typecheck clean on the released commit's `dev`; chorus-admin 31 pass, `check:site` verified 5 downloads.
- Preview `2.0.0-preview.4`: the package from the release installed with install.sh into temporary folders and served
  (`--host 0.0.0.0` listening). GitHub's release download links answered 504 from this network that hour, so the files came
  through `gh release download`.
- Production, after the website deploy: `release.json` and `install.sh` at 2.0.0, every download 200, `curl … | sh` installs 2.0.0
  into temporary folders; the box image built for 2.0.0 (amd64, arm64).
- The box end to end on a Mac (arm64): `.chorus/proof/feature-browser-everywhere/` (not committed).
