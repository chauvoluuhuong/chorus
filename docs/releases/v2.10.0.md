# v2.10.0

Released 2026-11-20, tagged on `v2.10.0-preview.1` (the same commit, a50218e, so the same bytes), approved by the owner on
2026-11-20 ("release production for latest preview"). Install: `curl -fsSL https://chorus-cli.web.app/install.sh | sh`.

## What
- In a chat, the right sidebar (Task, Artifacts, Activity, Record) closes on a click anywhere else in the chat page: the agent's
  screen, the banners, the ask card, the chat head. Desktop and tablet widths; the phone layout and the left sidebar are
  unchanged. It closes after the click, so the click still reaches what was under it (the terminal takes focus, chat-head
  buttons work). The closed state is remembered per chat, as with ✕.
- Vietnamese typing (Telex, VNI, OpenKey) in the chat terminal; Enter in Chorus's boxes waits for a word being composed.
- The paid module gets a live chats getter; agents are told the user starts a task in How to run.
