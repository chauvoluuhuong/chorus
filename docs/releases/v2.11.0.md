# v2.11.0

Released 2026-11-21, tagged on `v2.11.0-preview.2` (the same commit, f6e41e9, so the same bytes), approved by the owner on
2026-11-21 ("approve v2.11.0"). Install: `curl -fsSL https://chorus-cli.web.app/install.sh | sh`.

## What
- Sidebar (Pro): a chat that owns 2 or more tasks is one row with its tasks under it: the chat's title, "N tasks", its agent
  letter and the red count while folded; the tasks not done under it (├ └), the done ones folded into "✓ N done". The owner row
  opens the chat; a task row opens the same chat and picks that task (lit, Details, its Step line; the owner row outlined). The
  chat's band under its header lists the tasks it owns as OWNS chips. A one-task owner keeps its task row as before
  (chorus-core 01e39d4).
- Vietnamese typing keeps a word's first letter when keys overlap; on Linux with IBus (ibus-bamboo) each word is sent once and its
  forwarded Enter does not send a box. A typing recorder for input-method bugs.
- Doctor lists the channel check for Claude only.
