# v2.13.0

Released 2026-11-23 on the owner's word ("deploy them all to production", after trying previews 2, 3 and 4). Tagged on the
Release merge commit ef2692f, which differs from `v2.13.0-preview.4` only by the version in `package.json`. Install:
`curl -fsSL https://chorus-cli.web.app/install.sh | sh`.

## What
- **The Chat view** ([features/chat-view.md](../features/chat-view.md)): a second way to look at a chat beside the agent's own
  terminal, drawn from the turns Chorus captures. Replies as Markdown (tables, code, mermaid), tool calls folded with their
  detail on a click, cards for sub threads, new chats and files. A phone opens a chat in it; a tablet and a desktop open in the
  terminal as before. The switch is **Terminal | Chat**.
- A message box in the Chat view on every size, with the `/` (skills and the agent's own commands) and `@` (files) lists.
- Text the user did not type (background-job notices, a shortened conversation's summary, card answers, Chorus's own messages)
  shows as quiet lines, not as the user's bubbles.
- **Files** is the one name for what an agent reports, on every size (the desktop said Artifacts).
- The `/` list shows a skill once when it is in two folders (New chat too).
- chorus-core ea9f23b (its `main`): tool call kinds, a call's detail on request, the agents' own commands, the menu signal.
