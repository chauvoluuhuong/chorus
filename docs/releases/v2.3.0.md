# v2.3.0

Released 2026-11-13, tagged on `v2.3.0-preview.8` (commit `98a5eda`), released on the owner's word ("when you finish fixing admin
page let's release production no need to ask me"). Install: `curl -fsSL https://chorus-cli.web.app/install.sh | sh`.

## Evidence

- `npm test` 237 pass of 238 (the one failure, `serve --host <name>`, fails on the machine it was run on before these changes too)
  and typecheck is clean; chorus-core 283 pass, chorus-admin 60 pass. Every job of the preview and production builds succeeded,
  including the paid module.
- `v2.3.0-preview.8` installs into temporary folders as 2.3.0-preview.8; production installs with the plain command as 2.3.0.
  The live `release.json` says 2.3.0 and each download answers 200.
- The Planner loop ran once with the real Claude Code: the Planner asked its questions in one batch, asked for the grant, started
  step 1 from its own chat with the skip-permissions flag, and a Worker's question went to the Planner and its answer came back.
- Typing into a running chat, and into an ended chat after resuming it, was probed on Claude Code 2.1.323, Codex 0.164.0 and
  Antigravity 1.5.7 (chorus-core `docs/integrations/pro-probes.md`, P11).
- In the installed preview: `fable` in New chat's Claude list, Remote access setup opening on Install Tailscale, the right
  sidebar's buttons, no Doctor popup when every installed agent can be used, and the `/` and `@` lists staying open while typing.

## Not yet checked
