# v2.14.2

Released 2026-11-25 on the owner's word ("Approve v2.14.2"), after an end-to-end test from a phone over the private link with the
Planner. Tagged on the Release merge commit eff4611, which differs from the local preview 2.14.2-preview.202611251149 (dev a6d4da5)
only by the version in `package.json`. chorus-core `main` 0158555 (PR #84). Install: `curl -fsSL https://chorus-cli.web.app/install.sh | sh`.

## What
- **A phone always opens a chat in Chat.** A Terminal choice remembered on a phone kept every chat in Terminal; now Terminal lasts
  for that chat while it stays open. Tablets and desktops keep the last choice as before.
- **A file path in a reply opens the file viewer** (`tiem-banh-may.html`, `/Users/…/index.html`, `~/notes.md`). The Planner named the
  file its task made with a shell command, which was never reported, so a phone had nothing to tap. Through the private link only
  files inside the chat's project open; on the Mac a type the viewer can't show opens in the Mac's app.
- **The paid module on a phone** (chorus-core): the Portal's Needs you, Home and Approvals use the request cards of the mockup
  (one title line, the kind and wait, two equal answers, then Open task); a failure's title stays on one line; a goal's chip sits
  under its count.
