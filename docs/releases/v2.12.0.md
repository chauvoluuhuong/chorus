# v2.12.0

Released 2026-11-22, tagged on `v2.12.0-preview.1` (the same commit, 782bb95, so the same bytes), approved by the owner on
2026-11-22 ("Approve v2.12.0"). Install: `curl -fsSL https://chorus-cli.web.app/install.sh | sh`.

## What
- The phone layout (≤ 640 px) is redrawn: Home opens on the request that waits for you with its answer buttons, one counts
  strip, chat rows with the agent's letter and a state dot, projects as rows; Chats is one card per project; New chat has
  labelled picker rows and Start at the top right, each picker a sheet; a chat runs edge to edge with one row of tabs and a
  docked request card; Approvals and More use the same cards and drawn icons; a new tab bar. Tablet and desktop are unchanged.
- Sync skills: Edit and the agent tick-boxes are touch sized on a phone and a tablet.
- Proof scripts no longer register an installation with the backend (they set `CHORUS_NOTIFICATIONS=0`).
- Pro (chorus-core 605060c): touch sizes, Home shows Chorus's first request, the sizes stage of the Pro e2e renders again.

## Evidence
- `npm test` 459/459 and typecheck on the release commit (55f0820, the tree of 782bb95). The build session reported
  `proof:desktop -- --sizes` 86/86 at phone, tablet and desktop, light and dark; its phone screenshots were compared with the
  mockup for Home, Chats, More, New chat, a chat and Approvals.
- chorus-core `main` brought up to `dev` (chorus-core PR #78) before the tag; Release PR #118 merged into `main`.
- Preview `v2.12.0-preview.1` (release.yml run 45024900568) built every job, was installed with `--preview` into temporary
  folders, its `chorus serve` started and its `style.css` is the release's.
- Production `v2.12.0` (run 45025370034, chorus-core main) built every job; the darwin-arm64 bundle matched `SHA256SUMS` and its
  `chorus serve` started.
- Website: chorus-admin PR #56, deploy run 45025959872 green. Live `release.json` says 2.12.0, `install.sh` has
  `VERSION="2.12.0"`, every download URL answers 200, and a plain-command install into temporary folders installed 2.12.0 and its
  `chorus serve` started.

## Not yet checked
- No run on a real phone: the on-screen keyboard, the browser's address bar and the private link are unproven with the new
  layout. The preview was not used by the owner before production.
- The Pro screens (Portal, Processes, Teammates, Remote access) keep the earlier phone style; their v2 mockup is not drawn.
- In a chat, a request card with several options covers much of the agent's screen until it is folded.
- The Linux bundles are built and their checksums verified, but not started. The list in [v2.3.0](v2.3.0.md) still stands.
