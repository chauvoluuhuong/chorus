# v2.14.3

Released 2026-11-26 on the owner's word ("merge and release it on production"), after the owner tried the local preview
2.14.3-preview.202611260815 (dev 6e0d05e) on a phone. Tagged on the Release merge commit c2e10a3, which differs from that preview
only by the version in `package.json`. chorus-core `main` 46a9138 (PR #85). Install: `curl -fsSL https://chorus-cli.web.app/install.sh | sh`.

## What
- **The running call stays in view in Chat on a phone.** When the message box below the chat grew (a longer draft, the keyboard), the
  last line, often the tool call that was running, slid under it. A reader at the bottom now stays at the bottom; one who scrolled up
  to read stays where they are.
- **The phone Portal lists every task** (chorus-core). Every group of the board is open as in the mockup, Done included, so a project
  whose tasks are all done no longer looks empty behind a folded "Done 10". Done still folds with a tap, on its own, apart from the
  sidebar's done lists.
