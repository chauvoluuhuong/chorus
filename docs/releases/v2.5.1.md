# v2.5.1

Released 2026-11-14, tagged on the `v2.5.1-preview.N` built from the release commit (the same bytes), approved by the owner
("approve v2.5.1"). It rests on preview `v2.5.1-preview.1`. Install: `curl -fsSL https://chorus-cli.web.app/install.sh | sh`.

## What
All changes are in the paid module; the app itself is the same as 2.5.0.
- Sidebar: a click on a task's row brings the task's Plan chat (the Planner's chat that created it, the newest when there are
  several) to the front and unfolds the task. Task details opens from the row's "Details" chip; the arrow only folds and unfolds.
  A task with no Plan chat still opens Task details.
- How to run: a Permissions card above Start with "Grant all permissions" (and "Take back" once granted). Start from that page
  then starts the Workers with skip-permissions until the task is done. It is the same grant the Planner's question card gives.
- Tasks never wait for each other: a started task begins its step 1 at once, even when another task works in the same folder,
  as long as there is room under the Worker limit. Inside a task, steps still run one after another.

## Evidence
- chorus-core `npm test` and `npm run typecheck` pass; the Pro proof stages pass with stand-in agents: sidebar sb.1–sb.4
  (sb.2 rewritten for the new row click), a new check for the grant on How to run, planner-loop.
- Preview `v2.5.1-preview.1` built every job (version, pro-bundle, the 3 builds, release), was installed into temporary folders
  and started, and its Pro module has the three changes.
- The production build bundles chorus-core `main`, brought up to `dev` before the tag.
