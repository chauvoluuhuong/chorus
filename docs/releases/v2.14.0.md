# v2.14.0

Released 2026-11-25 on the owner's word ("Approve v2.14.0"). Tagged on the Release merge commit 76ad05c, which differs from
the local preview 2.14.0-preview.202611250945 (dev 800a461) only by the version in `package.json`. Install:
`curl -fsSL https://chorus-cli.web.app/install.sh | sh`.

## What
- **Opening a chat's file** ([features/chat-view.md](../features/chat-view.md) → Opening a file): one ↗ Open on every file card in
  the Chat view and every row of the Files list, the two behaving the same. A file Chorus can show opens in a viewer, always in
  Preview first with Raw one click away: markdown (with mermaid), HTML (sandboxed, desktop or phone width), mermaid, JSON (a
  folding tree), CSV/TSV (a table), diff, images, SVG, PDF, and Word (.docx) and Excel (.xlsx), which Chorus reads on the Mac
  without changing the file; code and plain text in Raw. Other files open in the Mac's own app; over the private link they get a
  short message ("Keynote files can't be opened here", or "This file stays on your Mac" for a file outside the chat's project).
- **The private link's address as a QR code** (chorus-core, paid): on the Add a device step and under Address on the Private link
  tab, so a phone opens Chorus by scanning it. The pairing code is still typed.
- chorus-core 7836afe (its `main`, brought up to `dev` by chorus-core PR #81).
