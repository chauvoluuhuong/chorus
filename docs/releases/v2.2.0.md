# v2.2.0

Released 2026-11-10, tagged on `v2.2.0-preview.5` (commit `cf159f6`), released on the owner's word ("ok release production for
it"). Install: `curl -fsSL https://chorus-cli.web.app/install.sh | sh`.

## Evidence

- `npm test` 209 pass and typecheck is clean; chorus-core 266 pass, chorus-admin 56 pass. Every job of the preview and production
  builds succeeded, including the paid module.
- The preview installs into temporary folders as 2.2.0-preview.5; a fresh home gets the preview paid module.
- Remote access: the stage 7 e2e, 11/11 with a stand-in `tailscale` and Funnel; in the app, a phone-sized browser typed the code
  (a wrong code, then the right one) and opened Chorus; a stranger gets a plain 404.
- A real card purchase on the live account (100% code): paid in Polar, and after two fixes in this release the account and the
  installed app show Pro.

## Not yet checked

- A real bank transfer on the live account.
- Remote access through real Tailscale Funnel from a phone with no Tailscale (Tailscale was off on the owner's Mac).

## Changes

### Features
- Remote access with nothing to install on the phone or laptop: Chorus is on this Mac's address through Tailscale Funnel, and a
  device gets in by typing the code the Mac shows (5 tries, one device, 10 minutes); with nobody adding a device the address is a
  plain 404. Setup no longer asks to install Tailscale on the phone.
- Running a task's steps in parallel is hidden for now.
- The app tells the licence server its version, so a preview gets its own paid module and never changes what production runs (8299121).
- The Pro plan box shows the signed-in email; Buy Pro for Community; Upgrade from a trial's first day (e08ed00).

### Fixes
- Upgrade on an account that already paid takes the paid licence at once (b684c8d), and a plan that changes on the server reaches the
  running app without a restart (chorus-core).
- The Portal's Goals tile fits on one line; the Pro feature card's style (chorus-core).

### Website and backend (chorus-admin, deployed with this release)
- Terms in English and Vietnamese (`/terms`, `/vi/terms`); the payment page says what to know before paying and links the Terms in
  the buyer's language.
- A paid order finds its Chorus account even when the buyer is already a customer of another app in the same payment account.
- Admin: loading and error states on Notifications, Analytics and CLI versions.

### CI
- The paid bundle's ids come from repository secrets (7e1ffc5); previews publish it to `current/preview/` through the Storage upload API (ed0ce30, e83f2e0).
