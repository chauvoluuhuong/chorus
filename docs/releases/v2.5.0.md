# v2.5.0

Released 2026-11-14, tagged on `v2.5.0-preview.2` (commit `10d856b`), released on the owner's word ("please finish and release
production when you done"). Install: `curl -fsSL https://chorus-cli.web.app/install.sh | sh`.

## What
- Report issue on the Doctor page: screenshots (pick, drop, paste), an optional email and the collected setup details; the report
  goes to the Chorus backend, not to GitHub, and the dialog shows a reference. `chorus doctor --report` is unchanged.
- The Welcome screen says which AI CLI fits best today; New chat has one faint line for Codex and Antigravity.
- The sidebar tree under a task follows its threads (Plan, each step, a step's sessions, Review); each row opens its own thread,
  and the task's row opens Task details instead of the task's newest thread.
- The first launch after an update runs the new paid module. Before, it ran the saved one and the new one only from the launch
  after, so a fix in that module looked missing right after updating.

## Evidence
- `npm test` 244 pass of 245 (the one failure, `serve --host <name>`, fails on the machine it was run on before these changes too)
  and typecheck is clean; chorus-core 292 pass, chorus-admin 74 pass. Every job of the production build succeeded; it bundled
  chorus-core `main`, brought up to `dev` before the tag.
- Proof stages with stand-in agents: the report dialog and Welcome 12 of 12; chorus-core's sidebar 4 of 4, planner-loop 8 of 8,
  waiting-items 6 of 6.
- From `v2.5.0-preview.1`, installed into temporary folders, a real report with a screenshot was sent to the live backend and its
  record and image were stored.
- The macOS bundle was downloaded, checked against `SHA256SUMS` and started with a temporary home before publishing; after the
  website was updated, a plain install into temporary folders installed 2.5.0 and started the same way; `release.json` says
  2.5.0 and every download answers 200.

## Not yet checked

- The Linux bundles were built and their checksums verified, but not started. The list in [v2.3.0](v2.3.0.md) still stands.
