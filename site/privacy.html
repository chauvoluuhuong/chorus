Chorus

Privacy policy

Last updated: 22 October 2026

Chorus is made by an individual, chauvoluuhuong. Chorus runs on your Mac. There is no Chorus account and no Chorus server: nothing you do in Chorus is sent to the author.

What Chorus keeps on your computer

  • Your chats. For each chat: its title, the agent and model, the project folder, what you asked and what the agent answered, the tools it used (a file path, a command, a test result), token use and plan-limit readings. This is the shared memory every agent reads.
  • Artifacts and skills. Files agents save for a chat, and the skills you turn on.
  • Where. In ~/.chorus/ (the memory, chorus.db) and in a .chorus/ folder inside each project. Delete a chat from the app, or delete these folders, and it is gone.

What leaves your computer

  • Your agents' own traffic. Claude Code, Codex and Antigravity talk to Anthropic, OpenAI and Google as they always do, under those companies' terms and your own plan. Chorus does not add anything to it, except that an agent reads the shared memory when you continue a chat with it, so that summary becomes part of what that agent sends to its provider.
  • Nothing else. The app's window talks only to a server on your own Mac (127.0.0.1), protected by a random token.

Installing

The install command downloads Chorus from this website and its open-source parts from the npm registry. Those requests are seen by Google (which hosts this site) and npm like any download.

This website

This website uses no analytics and sets no cookies. Google, which hosts it, keeps standard request logs.
