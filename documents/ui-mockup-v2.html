Chorus · UI mockup v2

Chorus desktop app

Pick a moment to see how it works. Each one matches a use case in documents/ui-use-cases.md. Everything inside the window is clickable.

The right side is for you

The right panel only opens when something needs you: an approval, or an artifact an agent made (a page, an image, a document). Otherwise the chat has the full width.

Agents work like models

Pick Claude Code, Antigravity or Codex in the message box, the way you pick a model in Claude. Switching mid-chat brings the new agent up to speed on its own.

Details have their own place

No technical mode. The full story of who did what, and what agents told each other, lives on the Activity page.
